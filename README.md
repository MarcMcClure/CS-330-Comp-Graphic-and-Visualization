# CS-330-Comp-Graphic-and-Visualization
Final Project for CS-330 Comp Graphic and Visualization at SNHU

Description

    For my Computer Graphics and Visualization class, I developed a custom 3D scene entirely from scratch using OpenGL libraries in C++. The project involved creating a collection of unique objects, complete with textures that I designed and meticulously mapped. Additionally, I built a custom camera engine to navigate the scene and implemented dynamic lighting with custom shaders, fully utilizing the graphics pipeline. I am proud of how this project turned out and thoroughly enjoyed the process, as it deepened my understanding of 3D graphics and allowed me to push the boundaries of what I could create.

To Run

    Running this requires GLEW, GLFW, glm, and SOIL2 which I have not provided here. I have included the tree of my Dependencies folder.

    Set up the required dependencies in a folder adjacent to the project Folder.

    Open using Visual Studio via File -> Open -> Project/Solution then select OpenGLSetUpProject.sln

Controls

    WASDQE the mouse to control the camera.

    L to change the lighting.

    P to change the perspective.

    F to reset the camera.

    T to toggle the Christmas tree.
