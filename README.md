# CS-330-Comp-Graphic-and-Visualization
Final Project for CS-330 Comp Graphic and Visualization at SNHU

Note: Running this requires GLEW, GLFW, glm, and SOIL2 which I have not provided here.

How do I approach designing software?

	What new design skills has your work on the project helped you to craft?
	
		this class was my first experience with 3D modeling, and I leaned quite a bit about how 3D objects are built as well as the graphics pipeline.
		
	What design process did you follow for your project work?
	
		My approach to this project was top down, I built the program framework first then filled in details and data as I went. This is partly because that is how the class was structured and partly because I was learning a new skill. While this is not generally my preferred development style it worked well for this project.
		
	How could tactics from your design approach be applied in future work?
	
		On advantage of this design approach that will be applicable to my future work is the utility of building a framework for testing before working on the project components. It would have been much more difficult to build my models if I would not see them as I added geometry and attributes.
		
How do I approach developing programs?

	What new development strategies did you use while working on your 3D scene?
	
		One development strategies that I used for this project was to write a handful of python scripts that could take the profile of an axially symmetric object, extrude it into a strip with a given angel, add colors, add normal, duplicate points, and produce indices as needed. I have used strategies like this before when doing data analysis, but this is the first time I have done so generatively, and I believe it sped up the process dramatically.
		
	How did iteration factor into your development?
	
		Each of my objects started as a untextured, single colored object. Then I added texture, a variety of colors, normal, and other data as needed. This iterative process helped avoid an accumulation of errors.
		
	How has your approach to developing code evolved throughout the milestones, which led you to the project’s completion?
	
		Once I had the framework done and the scripts developed my process remained fairly consistent from object to object.
